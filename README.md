# 📚 A Era Artificial - Landing Page
 
A responsive and elegant landing page developed to promote the book **A Era Artificial**. This project was built using **HTML5** and **CSS3**, providing users with information about the book and a direct purchase option through Amazon.
 
## 🚀 Features
 
- Responsive and modern design
- Clean and organized layout
- Book presentation section
- Call-to-action purchase button
- Amazon redirection for book purchase
- Built with pure HTML and CSS
 
## 🛠️ Technologies Used
 
- HTML5
- CSS3
 
## 📂 Project Structure
 
```text
├── index.html
├── style.css
└── assets/
├── images/
└── icons/
```
 
## 🎯 Objective
 
The purpose of this project is to create a simple and attractive web page that showcases the book **A Era Artificial**, encouraging visitors to learn more about the content and purchase it through Amazon.
